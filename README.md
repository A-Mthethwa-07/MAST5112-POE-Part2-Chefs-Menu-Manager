# Chef's Menu Manager – MAST5112 POE Part 2

A React Native/Expo mobile application for capturing and displaying restaurant menu items for Christoffel's Kitchen.

## Features
- Add dish name, description, course and price
- Choose Starter, Main Course or Dessert
- Validate required fields and price format
- Display menu items immediately after saving
- Show the newest item first
- Show empty-state, error and success feedback
- Keyboard-aware layout
- Basic accessibility labels for interactive controls

## Getting started
1. Install Node.js.
2. Install/open the Expo project used for the assignment.
3. Install dependencies with the project's package manager.
4. Start the Expo development server using the command specified by the project setup.
5. Open the app with Expo Go or an emulator.
